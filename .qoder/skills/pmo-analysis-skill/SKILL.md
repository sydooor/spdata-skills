# PMO 项目监控分析

## 触发条件

当用户需要以下操作时使用本skill：
- 分析开发任务数据、生成PMO报告
- 查看项目进度、人员工作量、模块分布
- 检查数据质量、逾期风险
- 每日/每周项目监控统计




关键词：PMO、项目监控、任务分析、开发任务、1455、进度报告、数据分析

## 使用方式

### 命令行

```bash
# 生成HTML报告（默认，报告日期为今天，输出到 outputs/ 目录并带日期）
python3 scripts/pmo_analyzer.py data/数据文件.xlsx

# 指定输出路径和日期
python3 scripts/pmo_analyzer.py data/数据文件.xlsx -o outputs/报告.html -d 2026/7/22
```

### 对话中使用

```
分析这个开发任务数据文件
```

## 分析内容

本skill生成包含以下全部板块的交互式HTML报告：

### 顶部 KPI 总览卡片
8个核心指标：总任务数、已完成、完成率、未完成、总人天、逾期数、临期预警数、项目标段数

### 紧急关注（报告最顶部，需优先沟通）
- **逾期任务清单** — 计划结束日期 < 报告日期 且未完成，含负责人、超期天数、延期原因
- **临期预警清单** — 报告日期 ≤ 结束日期 ≤ 报告日期+7天，需确认进度

### 一、项目标段完成率排名（批次 × 系统类型）
所有项目按完成率排序，含总任务/已完成/完成率/人天/逾期/临期，支持JAVA/SAP分类标注

### 二、批次 × 系统类型 总览
- 各批次（A/B/C）任务分布柱状图
- 系统类型（JAVA-专业系统/SAP）饼图
- 批次KPI表格（按批次汇总完成率、逾期、临期）
- 系统类型KPI表格（JAVA vs SAP对比）

### 三、未完成任务明细（项目 × 批次 × 系统类型）
203条未完成任务的详细列表，包含：序号、项目、批次、系统类型、任务名称、类型、优先级、状态、负责人、计划结束日期、进度、延期原因

### 四、供应商团队绩效（批次 × 系统类型）
按供应商维度统计：总任务、已完成、完成率、未完成、逾期、临期，按批次和系统类型细分

### 五、模块完成率明细（批次 × 系统类型）
按模块维度统计完成率，识别瓶颈模块

### 六、FS → 业务测试 → TS 阶段漏斗
双维度对比图表：
- 全部任务在各阶段的分布
- 已完成 vs 未完成任务在各阶段的对比

### 七、批次上线时间节点 & 开发截止预警
- A批次上线 7/31（开发截止 6/30）、B批次上线 8/30（开发截止 7/30）、C批次上线 10/30（开发截止 9/30）
- 各批次截止状态（已超期/即将截止/正常）
- 超截止未完成任务数、已完成但超截止任务数

### 八、逾期 & 临期任务 — 延期原因与备注
逾期+临期任务合并视图，逐一列出：类型（逾期/临期）、项目、批次、系统、任务、状态、负责人、计划结束、进度、延期原因、备注
- 统计项目/批次/系统维度分布摘要（Counter.most_common）
- 统计延期原因填写率和备注填写率

### 九、月度完成趋势
按月的任务完成数量趋势折线图（已完成 vs 总任务）

## 质量专项报告（独立 HTML，`_数据质量专项报告_` 后缀）

与主报告共享同一数据源，由 `quality_renderer.py` 独立渲染：

### 一、填写规范违规 — 6 类检查规则
- 占位符违规 / 状态-进度不一致 / 日期格式异常 / 任务周期超标 / 条件必填缺失 / 系统特有字段缺失
- 含规则说明 + 违规样例 + 批次×系统/项目维度下钻

### 二、必填字段完整度 — 批次 × 系统类型
- **2.1** 18个必填字段各字段填写率
- **2.1.1** 项目字段完整度排名（Top 15，完整度升序）
- **2.2** 按批次×系统类型的完整度汇总
- **2.3** 未完成任务必填字段缺失 Top 50

### 三、已完成任务验收就绪分析
- **3.1** 各项目验收就绪汇总（项目×批次×系统）
- **3.2** 验收材料不全的已完成任务明细

## 关键业务规则

### 批次识别
从项目名称中提取：含「-A批次」→ A批次、「-B批次」→ B批次、「-C批次」→ C批次

### JAVA-专业系统 vs SAP 分类
JAVA-专业系统包含：智能仓储、合同管理、BPM、报销报账、共享融合、司库融合、MDG-JAVA、BPC前端、电子档案。其余为SAP。

### 逾期判断
```
结束日期 < 报告日期 AND 状态 NOT IN (已完成, 已取消)
```
使用日期比较而非「是否逾期」字段。报告日期默认为今天。

### 临期判断
```
报告日期 ≤ 结束日期 ≤ 报告日期 + 7天 AND 状态 NOT IN (已完成, 已取消)
```

### 批次上线时间节点
| 批次 | 上线日期 | 开发截止 | 说明 |
|------|----------|----------|------|
| A批次 | 2026/07/31 | 2026/06/30 | 开发需提前1个月完成 |
| B批次 | 2026/08/30 | 2026/07/30 | 开发需提前1个月完成 |
| C批次 | 2026/10/30 | 2026/09/30 | 开发需提前1个月完成 |

### 验收就绪条件
已完成任务需同时满足：
1. 业务测试状态 = 已完成（含实际开始/结束日期）
2. 系统测试报告 ✓
3. 集成测试报告 ✓
4. 回归测试报告 ✓

### 必填字段（18个）
任务名称、任务类型、选择类型、优先级、状态、负责人、进度、开始日期、结束日期、描述、FS状态、FS负责人、FS计划结束日期、业务测试状态、业务测试负责人、业务测试计划开始日期、业务测试计划结束日期、TS状态

## 数据要求

输入Excel需基于「1455推广_开发任务跟踪模板_V1.0」，核心列包括：
- 项目、任务名称、任务类型、选择类型、优先级、状态、负责人、进度
- 开始日期、结束日期、是否逾期、计划开发人天
- 模块、需求类型
- FS状态/负责人/计划结束日期/实际结束日期
- 业务测试状态/负责人/计划开始日期/计划结束日期/实际开始日期/实际结束日期
- TS状态/计划结束日期/实际结束日期
- 系统测试报告、集成测试报告、回归测试报告（验收用）
- 延期原因、备注

分析脚本位于 `scripts/pmo_analyzer.py`，支持HTML输出格式。
